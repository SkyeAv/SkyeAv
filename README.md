## Featured Projects

- [Tablassert](https://github.com/SkyeAv/Tablassert) — Extract knowledge assertions from tabular data into NCATS Translator-compliant KGX NDJSON, with entity resolution and quality control built in.
- [Babel](https://github.com/NCATSTranslator/Babel) — Creates cliques of equivalent identifiers across many biomedical vocabularies.
- [biolink-model](https://github.com/biolink/biolink-model) — Schema and generated objects for the Biolink data model and upper ontology.
- [Translator Component Toolkit](https://github.com/NCATSTranslator/Translator_component_toolkit) — Python library for exploring and querying knowledge graphs across the Translator ecosystem.
- [RTX](https://github.com/RTXteam/RTX) — Software for Team Expander Agent (Oregon State U., Institute for Systems Biology, Penn State U.).
- [Shepherd](https://github.com/BioPack-team/shepherd) — A shared platform for Translator ARA implementation.
